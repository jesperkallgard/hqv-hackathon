The start page begins with an onboarding question: “What are you interested in seeing on this page?” The answer sets the first view, pins that section at the top, and stays remembered in a cookie for next time.

- The question uses pill-shaped answer buttons with the labels “Economics”, “Feature releases”, “Who to contact”, “KPIs”, and “Current issues”.
- Choosing an answer changes what is shown first rather than hiding the rest of the page.
- The selected section stays pinned at the top so the page opens with the most relevant content immediately visible.
- The choice is saved so the same experience comes back on the next visit.
- The change is the one thing to get right before anything else because it makes the page pleasantly digestible without turning it into a filtered-only view.

Build a first-question interaction on the page, not a separate flow. The wording is exactly: “What are you interested in seeing on this page?” The answers are shown as pill-shaped buttons and must use the exact labels “Economics”, “Feature releases”, “Who to contact”, “KPIs”, and “Current issues”. When someone chooses one, the page should reorder so that section is shown first and pinned at the top, while the rest of the page stays available below. The choice is stored in a cookie so the same view comes back next time. This sprint does not decide any deeper collapse/expand behavior beyond pinning the chosen section; that remains open.
