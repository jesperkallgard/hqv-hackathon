The page changes by adding a featured recently added features area at the top, so the newest feature is surfaced first and the rest stay browsable underneath.

- One feature is highlighted at the top as the main recent addition.
- The section includes a carousel below the highlight for the other features.
- The carousel shows 3 features at a time.
- Each feature shows a title, a short description, the author name, and an image.
- This is the one change to make before any other because it gives the page a clear newest-content entry point without changing the rest of the site.

Build a top section for recently added features. It must show one highlighted feature above a carousel that contains the other features, with 3 features visible at a time. Every feature card needs a title, a short description, the author name, and an image. The section should be the single named change for this sprint, and the rest of the existing page stays as it is. No new site, no extra content types, and no placeholders beyond the feature content itself.
