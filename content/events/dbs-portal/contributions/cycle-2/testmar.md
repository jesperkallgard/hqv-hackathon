The portal has one front page with five named doors — What changed, Playbooks, Rollout status, Decisions, Who to ask — and the front page is nothing but those five doors, no table repeated on it.

- Five doors: What changed, Playbooks, Rollout status, Decisions, Who to ask — the canon's own table categories, turned into places instead of filter values.
- The front door shows the five doors and one line each, not the table — arriving is a choice of where to go, not a wall of rows.
- "What changed" opens onto sprint 1's table; the other four aren't built yet and the front door says so plainly instead of pretending they're full.
- "Who to ask" is a door, not a footer line — the canon's own rule that every row needs a named owner is exactly why it deserves one.
- No search, no tiles with numbers, no icons — each door is a navy heading and one plain sentence, because a door you decode isn't one you see.

**What this is:** the front page of the DBS portal, sitting above the table the canon already built. It answers "where do I go" before the table answers "what changed."

**The five doors, in this order, each a navy heading with one sentence under it (their real wording, not filter labels):**
1. **What changed** — "What we tested, what we shipped, and what it did." Opens onto the existing table (Rolled out / Running / Decided against).
2. **Playbooks** — "How to run a test the way DBS runs it, written down once instead of explained again." Not built yet.
3. **Rollout status** — "What's live, where, and since when." Not built yet — note this overlaps with rows already inside "What changed"; whether it's a separate door or a filtered view of the same table was not settled by this group and is left open.
4. **Decisions** — "What we chose not to do, and why." Not built yet.
5. **Who to ask** — "Every area, with the person who owns it." Not built yet, but directly required by the canon's existing rule that no row goes up without a named owner — this door is where that name lives.

**The front door itself:** just the five doors stacked in one column, navy heading + one grey sentence each, on the flat white panel style already set. No table, no numbers, no icons. Below the fifth door, one plain line: "Playbooks, Decisions and Who to ask are named but not built yet." That line is not decoration — it's the honest state of the site and should stay until it's false.

**Look and feel:** matches the direction already set for the canon — white, sparse, navy headings, one column, flat panels, no shadows, no hero. This door page should look even quieter than the table screen, since it's doing less: five headings and five sentences, a lot of air between them.

**Out of scope:** we did not design what's inside Playbooks, Rollout status or Decisions — only that they exist and what one sentence each says about them. We did not resolve whether Rollout status duplicates rows already in What changed; that's a real open question, not an oversight.

**Assumption made because the sprint ended before this group had a working conversation:** the five doors are the canon's own content types (Playbook, Test result/Rollout status, Decision) plus the nav items the canon already named (What changed, Who to ask), rather than a new set invented from scratch. This felt like the safest reading of "which areas live on" — it builds on what already won, rather than adding a sixth voice.
