A web front door for colleagues who need the DBS picture fast: one page, one glance, with visual state cards and clear owners. It answers which start page by showing what each section carries, in what order, and what is biggest.

- Header first, with DBS name and short navigation, then a large hero that is the biggest thing on the page.
- The main content stays in one generous column, broken into scan-first cards that can be read without a guide beside you.
- Status is shown as coloured round tags and state columns for ongoing, planned and done, so progress is visible at a glance.
- Each post can carry an icon, an image of the responsible person and a citation from a team member when that helps make the change real.
- The page keeps the white, airy, navy-led look, with orange primary pills and outlined navy secondary buttons, and it is a website front door, not a wiki.

## Build this as the start page for DBS
- Keep the page a real internal website front door, not a document or wiki.
- Use the existing DBS structure and content as the basis for the page.
- The layout must be: header with site name and short nav first, then a large hero, then the main content in one generous column, then footer.
- Make the hero the biggest element on the page.
- Add scan-first cards for areas/posts so they can be taken in at a glance.
- Add visual status treatment using coloured round tags for states.
- Split the state presentation into three columns: ongoing, planned, done.
- Include icons where useful.
- Include an image for the responsible person on posts or cards where it helps recognition.
- Allow a citation quote from a team member on posts where it supports the change.
- Keep the look white and airy with navy headings and left-aligned text.
- Buttons stay fully round pills: orange with white text for the primary action, outlined navy for the rest.
- Do not turn this into a wiki, a dense dashboard, or a page that needs instructions to read.
- Do not add placeholder content.
- Keep content real and outcome-led: say what changed and what it meant, not what was done.
- Preserve the track and BU naming already used in canon, one word each.
- Preserve the existing owner-as-person rule; the team is not the owner.
- If an image, quote or icon is not known, leave it out rather than inventing it.
