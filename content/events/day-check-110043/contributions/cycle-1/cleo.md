One list, newest first, that answers the three things people keep asking a colleague instead of the site.

- The whole first screen is one list called "What's changed", newest first — nothing else on it.
- Every row is one line, plus an owner's name and a date. No paragraph, no summary underneath.
- No search box, no filters, no categories. If it needs a search box, it's too long — trim the list, don't add search.
- It has to answer three things without anyone asking a colleague: what changed on the site this week, what's being tested right now, and who owns the dealer locator.
- A row only goes in if it saves someone from asking. Status updates with nothing to act on don't earn a place.

## What it is

A single page, titled **What's changed**. One column, one list, newest entry at the top. Nothing above it but the title, nothing beside it — no search box, no tabs, no sidebar.

## Row format

Each row is exactly:

`[one line of what changed] — [owner name], [how often it's updated]`

No second line, no description underneath. If a change needs more than one line to explain, that's a sign it's the wrong length, not a reason to add a second line.

## Example rows (real content, not placeholders)

- **Dealer locator now shows opening hours from the store feed, not the static list.** — Priya Nair, updated whenever the store feed changes.
- **Homepage hero is running a two-version test against last month's version.** — Priya Nair, updated weekly.
- **Dealer locator is owned by Priya Nair.** — updated whenever ownership changes.

Assumption: Cleo didn't have a name for who owns the dealer locator on hand, so I've put Priya Nair in as the example owner. That name is not confirmed — swap it for the real one before this goes live.

## What it refuses to do

- No search box, ever. If the list gets long enough to need one, the fix is to remove rows, not add search.
- No archive or history page. Old rows just fall off the bottom.
- No comments, no reactions, no way to reply on the row.
- No categories or tags splitting the list into sections. It's one list because the three questions people ask are all answered by scanning the top of it, not by filtering to find one.

## Look

White background, a lot of air between rows. Navy for the "What's changed" heading, left-aligned. Flat panel per row, no shadow, no card styling that makes it look like a product feed — it should read like a page someone typed, not a page someone designed.
