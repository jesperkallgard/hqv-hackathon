We agreed the page should have exactly this, in this order, and nothing more:

1. Full-width product photo
2. Model name
3. Price — the most prominent thing on the page after the photo
4. Three spec bullets: weight, frame size, drivetrain
5. A "Buy Now" button that's unmistakably clickable — solid fill, big, not a thin link

No reviews, no related products, no testimonials, no spec tables, no carousel. People trust a page they can scan in five seconds more than one they have to dig through.

We used a real bike so this is credible from day one — Trek Marlin 7 Gen 3, current UK/US retail:

- **Trek Marlin 7 Gen 3 — $1,299**
- Weight: 32.7 lbs (14.85 kg, size M)
- Frame sizes: XS–XXL
- Drivetrain: SRAM SX Eagle, 1×12

**Open item:** we were mid-way through building the actual working page component (a data-driven `SimpleBikeProductPage` block — photo, name, price, 3 specs, full-width Buy Now button, styled to the theme) when the clock ran out. The build didn't land in time, so this hand-in is the spec and the real data, not yet the clickable prototype. Whoever picks this up next has everything needed to finish it in minutes: the exact five-part structure above and the real numbers to drop in.
