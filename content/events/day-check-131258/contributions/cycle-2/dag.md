A short "coming up" list on the page: questions that have been asked twice and are waiting to be written up, so people can see one is on its way instead of asking a colleague anyway.

- A visible list of questions that have been asked twice and are waiting to become a post — not full posts yet, just the question.
- Each queued question names who it was asked to, so it's clear whose job it is to write it up.
- A queued question disappears from this list the moment it becomes a real post — it never sits in both places.
- The list stays short on purpose: three or four lines, not a backlog anyone has to triage.
- Nobody adds to the list from the page itself — Ines adds a question here the second time she's asked it, the same rule the footer already states.

## What was actually said this sprint
Dag's group didn't land on the part before the clock ran out; the only steer given was "maybe a list of some kind on it, whatever you think." This hand-in is that assumption, made concrete, built on the canon page rather than replacing any of it.

## What it is
A small section on the existing page, sitting near the "Write a post" button, titled something like "Coming up" or "Waiting to be written." It lists questions that have crossed the "asked twice" line the canon already sets, but haven't been written into a post yet.

Each line:
- The question, written as someone would ask it — e.g. "Why did staging go down twice this week?"
- Who it's been asked to, e.g. "Asked to: Bo"
- Nothing else. No date, no status tag, no priority.

## Content used (assumption, not confirmed)
No real queued question was named this sprint. Example used to show the shape: "Why did staging go down twice this week? — Asked to: Bo." Replace with a real one before this is treated as live content.

## Look and feel
Same as the rest of the page: flat panel, no shadow, navy heading for the section title, left-aligned, plain sentences. Not a separate page — a short block on the one page that already exists.

## Out of scope
No form to submit a question to the list. No count, no voting, no ageing indicator. If the list would ever need more than four lines, that's a sign a post should have been written, not a reason to add scrolling or pagination.
