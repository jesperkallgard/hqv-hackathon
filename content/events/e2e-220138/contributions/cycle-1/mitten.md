title: "Skip setup, start with a real example"
cycle: 1
pair: "mitten"
authors: ["Dag", "Ada"]

The first screen should not ask for setup.

It should open already loaded with a real example. Something working, not empty. Not a form, not a wizard, not a blank state waiting for input.

You land, and there is already something there to look at, use, and change.

No onboarding step comes before it.
